# Genomic Detective (Python 3.10+)

Учебный исследовательский прототип для приоритизации генетических вариантов по фенотипу. 
Он реализует структуру из ТЗ: загрузку данных, QC, параллельные анализаторы (фенотип, патогенность, наследование), интеграцию/ранжирование и объяснение результата.

> **Важно:** это не клиническая диагностическая система и не валидированный клинический бенчмарк. Результаты предназначены только для исследовательских и образовательных целей. Не используйте их для медицинских решений.

## Возможности
- **Вход:** Фенотипы в формате JSON (Phenopackets), а также TXT/CSV/TSV. Варианты в формате VCF или TSV.
- **Обработка JSON:** Извлечение HPO-терминов и флага `excluded` (исключенные признаки).
- **Внешняя аннотация:** Батч-запросы к Ensembl VEP REST API для определения гена, типа мутации и популяционной частоты (gnomAD AF).
- **QC-фильтрация:** Отсечение частых полиморфизмов (AF > 1%) и вариантов с низким качеством (QUAL/DP).
- **Параллельный анализ:** 
  - Фенотипический анализ (кастомный `HPOAnalyzer` на базе файла `genes_to_phenotype.txt`).
  - Эвристика наследования (учет гетерозигот/гомозигот).
  - Анализ патогенности.
- **Умное ранжирование:** Взвешенный рейтинг (Фенотип 50%, Патогенность 30%, Наследование 20%). Отсутствующие данные не занижают итоговый балл (исключаются из знаменателя).
- **Порог отсечения:** Если лучший кандидат набирает менее `0.3` баллов, система автоматически выдает `no_causal_variant_in_vcf`.
- **Выход:** Подробный JSON-отчет и `predictions.tsv` (строго по формату хакатона).
