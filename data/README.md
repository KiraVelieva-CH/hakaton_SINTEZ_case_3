# Геномный детектив — учебная версия
10 случаев: 6 development и 4 hidden. На случай одна аутосома, около 400 фоновых SNV GIAB HG002 и дополнительные реальные клинические варианты. Это synthetic composite genotype, не геном пациента. Фаза не сохраняется. Учебная панель не является клиническим бенчмарком.

Задача: ранжировать варианты по фенотипу и предложить причинный вариант либо no_causal_variant_in_vcf. Такой ответ допустим для любого случая. Формат predictions.tsv: case_id, prediction (колонки разделены табуляцией). Вариант записывается chrN:POS:REF:ALT, координаты 1-based GRCh38.

В *_variants.tsv содержатся только базовые характеристики вариантов. NA означает отсутствие аннотации, а не доброкачественность. VEP/ClinVar/gnomAD не использованы. Для решения потребуется самостоятельная функциональная аннотация. 

В HPO-профилях excluded=true означает отсутствие признака. У части случаев профиль сокращён. Идентификаторы проверены по HPO 2026-09-01. Независимая проверка REF по FASTA пропущена по согласованному учебному допущению. Все варианты — SNV; нормализация indel не требуется. BED получен, но выборка строится из benchmark VCF без дополнительной фильтрации BED.

Оригинальные Phenopackets, привязки вариантов к пациентам и скрипт сборки находятся у жюри.
