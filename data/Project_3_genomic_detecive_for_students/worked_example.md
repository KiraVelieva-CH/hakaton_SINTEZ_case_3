# Разобранный пример case_01
Опубликованная интерпретация: ген FBN1, заболевание OMIM:616914, вариант chr15:48412568:C:A, состояние heterozygous.
Источник: https://pubmed.ncbi.nlm.nih.gov/21594993.
Сопоставьте положительные и исключённые признаки в case_01_phenotype.json с описанием заболевания; найдите точную запись в VCF. Затем проверьте согласованность механизма болезни и аллельного состояния. Ответ взят из опубликованного Phenopacket, а не получен независимой клинической экспертизой. Наличие варианта само по себе недостаточно для диагностики.
